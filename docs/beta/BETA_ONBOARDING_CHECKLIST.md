# AegisOS Beta Onboarding Checklist

Use this checklist for each beta customer/team.

## 1) Pre-onboarding
- [ ] Beta contact(s) identified (operations + technical point of contact).
- [ ] Beta objectives captured (top 2–3 operational outcomes).
- [ ] Success metrics agreed (e.g., faster handover, anomaly detection time, manager visibility).
- [ ] Scope confirmed (which modules/routes are included for this team).

## 2) Account & access setup
- [ ] User accounts created and invited.
- [ ] Roles assigned correctly (operator, manager, admin where applicable).
- [ ] Tier/feature flags configured for agreed scope.
- [ ] Test login completed by each key user.

## 3) Environment/data readiness
- [ ] Rig/team context configured.
- [ ] Survey data imported or seeded for demo/testing.
- [ ] Plug records baseline set (if applicable).
- [ ] Telemetry source configured (or SIM fallback prepared).
- [ ] Timezone/unit preferences validated (SI/Imperial expectations).

## 4) Guided walkthrough (recommended 45–60 min)
- [ ] Login + navigation basics (Hub and route map).
- [ ] Live Ops usage: SIM/LIVE/STANDBY behavior and stale indicators.
- [ ] Wellbore/survey + plug management flow.
- [ ] Workbook/engineering workflow path.
- [ ] Team coordination flow (tasks/handover/relevant pages).
- [ ] How to report issues and request support.

## 5) User enablement package
Provide these to beta users:
- [ ] Quickstart document (10-minute path).
- [ ] Known limitations list.
- [ ] Support contact and expected response times.
- [ ] Weekly feedback review schedule.

## 6) First-week success checks
- [ ] At least one full core workflow completed by customer team.
- [ ] No unresolved P0/P1 issues.
- [ ] Feedback captured from first 3 active users.
- [ ] Friction points documented and triaged.

## 7) Weekly beta cadence
- [ ] Weekly review meeting held.
- [ ] Usage and reliability summary shared.
- [ ] Open issues prioritized by severity and impact.
- [ ] Next-week goals agreed.
